# GitHub Task: Quality Control database schema and module foundation

**Title**: [P39] Quality Control: Database schema and module foundation

**Description**:
Establish the Quality Control module foundation per PRD Phase 5. Introduce core Prisma models for inspections and decisions, RBAC wiring for QUALITY_CONTROL module, audit logging hooks, and API scaffolding. Production already records qualityStatus on rolls/bales and rejected/rework/scrap on runs; this module formalises QC as a first-class workflow.

**PRD references**: Section 40 Quality control, Section 41 Pass/fail/rework, Section 50 Cross-module traceability

**Depends on**: P26 roll stock (#217), P36 inventory integration (#227)

**Task Pointers (Checklist)**:
- [ ] **Schema**: Add `QcInspectionStatus` enum (PENDING, PASSED, FAILED, REWORK, ON_HOLD) and `QcInspection` model (referenceType, referenceId, inspectorId, decision, remarks, inspectedAt)
- [ ] **Schema**: Add `QcInspectionLine` or characteristic capture if needed for phase-specific QC fields
- [ ] **Migration**: `prisma/migrations/*_quality_control_foundation`
- [ ] **API**: Scaffold `/api/quality/inspections` with RBAC `QUALITY_CONTROL` module + `requirePermission`
- [ ] **Lib**: Helpers to resolve inspection target (roll, bale, production run) and update linked `qualityStatus`
- [ ] **Logging**: `logEvent` / `logDiff` on inspection create and decision
- [ ] **OpenAPI**: Register quality routes in swagger registry
