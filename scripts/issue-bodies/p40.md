# GitHub Task: Quality Control inspection queue and decision UI

**Title**: [P40] Quality Control: Inspection queue and decision UI

**Description**:
Build the QC operator workflow per PRD: queue of items pending inspection (rolls, bales, run outputs), inspect and record pass/fail/rework/hold. Updates qualityStatus on linked entities and blocks downstream use until passed where applicable.

**PRD references**: Section 40 Quality control, Section 41 Pass/fail/rework, Section 27 Roll stock quality status

**Depends on**: P39

**Task Pointers (Checklist)**:

- [ ] **API**: `GET/PATCH /api/quality/inspections/{id}` - view and amend inspection (with permission)
- [ ] **UI**: `/dashboard/quality` - module landing with pending queue count KPIs
- [ ] **UI**: Inspection detail form - pass, fail, rework, hold with remarks and optional characteristics
- [ ] **UI**: Link from roll detail page to QC inspection history
