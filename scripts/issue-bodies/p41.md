# GitHub Task: Quality Control rework workflow

**Title**: [P41] Quality Control: Rework workflow

**Description**:
Implement formal rework tracking per PRD. When QC fails or flags rework, create a rework ticket linked to the source item and route back into the appropriate production phase or roll stock. Close the loop when rework is completed and re-inspected.

**PRD references**: Section 41 Pass/fail/rework, Section 29 Planned vs actual (rework qty on runs)

**Depends on**: P39, P40

**Task Pointers (Checklist)**:
- [ ] **Schema**: Add `QcReworkTicket` model (inspectionId, sourceReferenceType, sourceReferenceId, targetPhase, status, assignedOperatorId, notes)
- [ ] **Migration**: `prisma/migrations/*_qc_rework`
- [ ] **API**: `GET/POST /api/quality/rework` - list and create rework tickets from failed inspections
- [ ] **API**: `PATCH /api/quality/rework/{id}` - assign, complete, cancel
- [ ] **UI**: Rework queue tab on `/dashboard/quality` - open, in progress, completed
- [ ] **Integration**: Completing rework creates re-inspection or auto-queues for QC
- [ ] **Logging**: Audit rework create, assign, complete with full diff
