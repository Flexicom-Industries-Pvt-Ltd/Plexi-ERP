# Plexi-ERP

Central CRM and Manufacturing ERP System for **Plascom Industries LLP**. 

## Architecture
This project is built as a majestic monolith designed for maximum traceability and performance.
- **Framework**: Next.js (App Router)
- **Database**: PostgreSQL (via Neon)
- **ORM**: Prisma
- **Auth**: NextAuth v5 (Role-Based Access Control)
- **Styling**: Tailwind CSS + Base UI / Shadcn UI
- **Storage**: AWS S3 (Presigned Uploads)
